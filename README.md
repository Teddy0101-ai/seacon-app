# Seacon 航运学院

基于《主流船型必须搞懂的知识白皮书》v2.1 从知识地图重新设计的纯静态学习 App。

## v3 重构结果

- 旧版 11 单元 / 56 节路径和全部旧题均已废弃。
- 新课程为 **16 单元 / 80 节 / 448 道题**，覆盖角色、船型、参数、租约、交易、保险、合规、市场、投资、融资与实务交付。
- 每节包含学习目标、微型讲义、关键清单、真实误区、来源章节和详细机制解析。
- 题型包括单选、判断、多选、排序、数量级判断和开放表达；错题会当场回炉并进入间隔复习。
- 保留并重新接入 **392 条术语知识库**，可搜中文、英文、缩写和别名。
- 新 UI 支持桌面三栏、平板和移动端：学习路径、智能复习、掌握度、热力图、每日任务、徽章、成长等级和离线 PWA。

## LLM 内容边界

题干、干扰项和解析由 LLM 依据白皮书知识点、常见误区和实务场景逐条综合撰写，并在构建期打包为静态数据。运行时不调用外部模型或 API，因此可完全离线使用，也不会把用户进度发送到服务器。

`build_data.py` 会校验单元、课次、题量、答案合法性、重复选项、空解析、题型覆盖、答案位置偏置和判断题方向偏置。教学数字只用于解释计算机制，不代表当前市场报价。

## 主要文件

```text
seacon-app/
├─ course_v3_schema.py    课程作者数据结构（不生成题目文本）
├─ course_v3_01.py … 08.py  16 单元逐题内容
├─ content_audit_v3.md    白皮书知识、误区与能力矩阵
├─ build_data.py          内容审计与 data.js 编译
├─ index.html             新页面与无障碍结构
├─ app.css                响应式设计系统和动效
├─ app.js                 路径、答题、SRS、术语和成长引擎
├─ data.js                课程构建产物
├─ terms.js               392 条术语构建产物
├─ build_assets.py        术语、PWA、缓存与图标构建
├─ manifest.webmanifest
├─ sw.js
├─ vercel.json
└─ icons/
```

## 构建与部署

```bash
python build_data.py
python build_assets.py
```

项目不依赖 CDN、后端或前端框架，Vercel Framework Preset 使用 `Other`。每次修改课程或前端文件后重新执行两个构建命令，Service Worker 会按内容哈希升级缓存。
